# Постоянная QA-сцена боя

Сцена предназначена для повторных проверок боя с двумя клиентами без ручной
настройки карты и существ перед каждым прогоном.

## Быстрый запуск

1. Открыть ГМ-клиент по адресу `index.html?qa_scene=1`.
2. Создать комнату и подключить отдельный клиент игрока.
3. В режиме редактирования открыть «Настройка сцены» и нажать «QA бой».
4. Сцена `QA — бой двух клиентов` автоматически создаётся либо обновляется,
   сохраняется в библиотеке и становится текущей.
5. Нажать «Запустить игроков», затем «Начать бой».

## Состав сцены

- фон: `images/map.jpg`;
- сетка: 20 × 14, клетка 64 px;
- привязка к сетке отключена;
- точка появления героя в центре;
- `QA Крыса`: ближняя атака `1d4+1`;
- `QA Стрелок`: дальняя атака `1d6`.

## Восстановление

Переносная резервная копия лежит в
`test-evidence/qa-combat-two-clients.scene.json`. Её можно импортировать через
«Сцены» → «Импорт JSON», если библиотека браузера была очищена.

## Два независимых клиента на одном компьютере

Для разделения локальных профилей можно открыть ГМ на `0.0.0.0:4173`, а игрока
на `localhost:4173`. Для проверки опубликованной версии использовать два разных
браузера или профиля.
