# Mobile derived-stat icons

Generated with the built-in image_gen tool from the approved concept 03, "Signs of the Wanderer".
Armor: aged silver faceted shield. Initiative: amber lightning in a broken ring.
Speed: two plain matching right-pointing chevrons; the earlier hooked tail was explicitly removed.

Original PNGs and prompts: output/imagegen/derived-icons-v3/ in the source workspace.
Runtime files: 256px WebP with alpha, normalized transparent padding, no CSS color filters.
Only the mobile Characteristics view consumes this set. Existing desktop assets are preserved.

Final speed edit prompt:
Edit this single game UI speed icon. Keep its pale sage-green worn faceted metal material and crisp dimensional bevels. Replace the irregular hooked shape with EXACTLY TWO IDENTICAL SIMPLE RIGHT-POINTING CHEVRONS: >>. Each chevron consists of just two straight diagonal strokes meeting at the right tip, equal-length top and bottom arms, straight flat cut ends on left. Mirror-symmetric top/bottom. No hooks, no tails, no curves, no third stroke, no extra decorations. Two matching parallel chevrons same size and even spacing. Center whole symbol on square transparent canvas, generous 12% margin. Preserve true alpha transparency, no background, no floor, no shadows outside the objects, no aura, no text. Broad clear readable silhouette appropriate for small mobile game UI.
