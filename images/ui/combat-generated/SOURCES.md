# Generated combat UI assets

Generated with OpenAI ImageGen on 2026-08-03, then chroma-keyed from `#ff00ff`, cropped to 256×256 RGBA, and visually checked at native size. These are original project assets; no third-party source images were used.

## Magic categories

Files: `folio.png`, `codex.png`, `ritual.png`, `innate.png`.

Prompt: production sprite sheet of exactly four isolated dark-fantasy RPG interface icons on a solid `#ff00ff` background: a blue leather foliant containing sealed magic, a martial codex represented by an enchanted instructional sheet, a ritual object made from a bone and rolled rite, and an innate power represented by a human silhouette with an inner golden vortex. Minimal silhouettes, antique gold and restrained category color, painterly realistic materials, no text, no frames, no shadows outside each icon.

## Combat action dock

Files: `movement.png`, `long-action.png`, `short-action.png`, `free-action.png`, `prepare.png`, `inventory.png`.

Updated 2026-08-04. `movement.png` and `inventory.png` are exact project-local copies of the approved free-room icons from `images/vtt-icons/`.

`long-action.png`, `short-action.png`, `free-action.png`, and `prepare.png` were generated individually with OpenAI ImageGen, using those approved boot and backpack files as visual references. Each source used a flat `#00ff00` chroma-key background and was converted to 256×256 RGBA with the project ImageGen transparency helper.

Prompt set: one isolated realistic hand-painted dark-fantasy object per icon, aged brown leather, worn steel or antique bronze, restrained warm rim light, strong sculpted volume and a silhouette readable at 48 px. Subjects: an armored leather hand holding a weighty longsword for a committed long action; a gloved hand snapping a compact dagger forward for a short action; a gloved hand flicking a worn coin for a free action; and an old hourglass protected by a buckled leather harness for a prepared reaction. No text, frames, badges, particles, or magical symbols.

## Time and turn UI

Prompt: production sprite sheet of exactly three isolated dark-fantasy time and turn symbols on a solid `#ff00ff` background: celestial world-clock dial, compact engraved round counter medallion, luminous turn marker. Antique brass, moon-blue enamel, restrained glow, readable at small interface size, no text and no surrounding UI panel.
