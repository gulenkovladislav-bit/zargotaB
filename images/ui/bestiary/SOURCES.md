# Bestiary UI icons

Generated for Zargota with OpenAI ImageGen on 2026-08-14.

- `types/large/`: grim hand-painted dark-fantasy creature portraits on transparent backgrounds.
- `types/mini/`: simple, strongly color-coded type pictograms designed to remain recognizable at 20–24 px.
- `threats/`: escalating threat pictograms from a single dagger to a region-scale black sun.

The prompts required isolated subjects, transparent backgrounds, no text or frames, a dark ink-painted finish, and a distinct silhouette for each semantic category.
