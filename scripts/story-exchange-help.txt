RU — Обычная работа
Открой «Обмен эпизодами.app», нажми «Подключиться» и держи редактор Зарготы открытым. Зелёный статус означает готовность. Коды и кнопки на сайте не нужны. «Создать резерв» сохраняет все эпизоды, «Отключиться» останавливает сервис. Консоль можно свернуть. Ручное подключение оставлено только для диагностики.

UK — Звичайна робота
Відкрий «Обмен эпизодами.app», натисни «Підключитися» та тримай редактор Зарготи відкритим. Зелений статус означає готовність. Коди та кнопки на сайті не потрібні. «Створити резерв» зберігає всі епізоди, «Відключитися» зупиняє сервіс. Консоль можна сховати. Ручне підключення залишено лише для діагностики.

4. Команды для помощника (из корня проекта):
   node scripts/story-exchange.cjs status
   node scripts/story-exchange.cjs list
   node scripts/story-exchange.cjs read EPISODE_ID
   node scripts/story-exchange.cjs apply FILE
Команда read печатает путь к рабочей копии. Редактируйте только поле episode, сохраняйте projectId, snapshotId и exchangeId. Перед редактированием берите свежую копию нужного эпизода. Не запрашивайте другой снимок до применения правки.
Снимки, рабочие копии и автоматические резервы лежат в .story-exchange/ (скрытая папка проекта, исключена из Git). connection.json содержит секрет подключения: его не публиковать.
Сохранение рабочего файла НЕ запускает запись в браузере. Для этого нужна отдельная команда apply. Перед отправкой правки сервис сохраняет резерв на диске. Редактор дополнительно сохраняет копию для отмены; если места не хватает, правка не применяется.
При конфликте снова получите эпизод и перенесите только нужные изменения. При потере ответа не отправляйте правку повторно: проверьте редактор, перезапустите сервис и получите новый снимок.
Запись в открытое поле или запущенный тест блокируют применение. Неподдерживаемые поля и некорректная структура отклоняются. Это проверка целостности, а не проверка сюжета: сюжетные изменения всё равно нужно проверять в игре.
Не редактируйте один эпизод одновременно в нескольких вкладках. При отключении связь прекращается; уже отправленная команда могла выполниться.
Остановить сервис: кнопка «Остановить» в приложении. В редакторе: «Вимкнути» / «Отключить».
Резерв эпизода содержит ссылки на картинки и звук; он не заменяет копию папки ресурсов.

UK — Локальний обмін епізодами
1. Відкрий «Обмен эпизодами.app» у корені проєкту та натисни «Запустити». Файл .command тепер також відкриває застосунок.
2. У редакторі: «Прямі правки» → «Обмін через папку». Натисніть у застосунку «Ключ підключення», потім вставте ключ → «Підключити».
3. Залиште редактор відкритим. Після оновлення сторінки підключіть його знову.
4. Команди для помічника наведено вище: status, list, read EPISODE_ID, apply FILE.
Команда read друкує шлях до робочої копії. Редагуйте лише поле episode, зберігайте projectId, snapshotId та exchangeId. Перед редагуванням отримуйте свіжу копію потрібного епізоду. Не запитуйте інший знімок до застосування правки.
Знімки, робочі копії та автоматичні резерви зберігаються у .story-exchange/ (прихована папка проєкту, виключена з Git). connection.json містить секрет підключення: його не публікувати.
Збереження робочого файлу НЕ запускає запис у браузері. Для цього потрібна окрема команда apply. Перед надсиланням правки сервіс зберігає резерв на диску. Редактор додатково зберігає копію для скасування; якщо місця бракує, правка не застосовується.
За конфлікту знову отримайте епізод і перенесіть лише потрібні зміни. Якщо відповідь втрачено, не надсилайте правку повторно: перевірте редактор, перезапустіть сервіс і отримайте новий знімок.
Редагування відкритого поля або запущений тест блокують застосування. Непідтримувані поля й некоректна структура відхиляються. Це перевірка цілісності, а не перевірка сюжету: сюжетні зміни однаково потрібно перевіряти у грі.
Не редагуйте один епізод одночасно в кількох вкладках. Після вимкнення зв’язок припиняється; вже надіслана команда могла виконатися.
Зупинити сервіс: кнопка «Зупинити» у застосунку. У редакторі: «Вимкнути».
Резерв епізоду містить посилання на зображення та звук; він не замінює копію папки ресурсів.
