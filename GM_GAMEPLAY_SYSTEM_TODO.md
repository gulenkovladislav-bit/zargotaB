# Заргота — система ведения игры ГМ

Статус: начата реализация  
Область: режим «Ведение», листы игроков, Firebase-комната, предметы, задания, статусы и боевые заклинания.

## Неподвижные правила

- Локальный лист игрока остаётся постоянным источником данных вне сессии.
- В активной сессии изменяется только выбранный герой игрока.
- Любая мастерская выдача имеет стабильный ID и применяется не более одного раза.
- Предмет или задание сначала надёжно сохраняются в листе игрока, затем подтверждаются в Firebase.
- Крупные изображения не должны бесконтрольно раздувать снимок комнаты.
- ГМ видит результат сетевой операции, а игрок — понятное уведомление без технического текста.
- Боевые эффекты изменяют одновременно боевую сущность, связанный лист героя и жетон сцены.

## Модель данных

```text
Локальная библиотека ГМ
  localStorage: zargota_gm_delivery_library_v1
    ├── items
    ├── quests
    ├── texts
    └── images

Выдача в активной комнате
  rooms/{code}/members/{uid}/gmDeliveries/{deliveryId}
    ├── kind: item | quest | text | image
    ├── mood: calm | solemn | ominous
    ├── showPopup
    ├── title / text / image
    ├── payload
    └── status: pending | applied | failed

Подтверждённый результат
  item  → character.inventoryItems
  quest → character.journalEntries
  text/image → подтверждение просмотра
```
