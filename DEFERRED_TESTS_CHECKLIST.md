# Заргота — полный список проверки

Один документ для последовательного теста всей игры.

## Как проходить

Нужны два независимых клиента:

- клиент 1 — ГМ;
- клиент 2 — игрок в другом браузере, профиле или на другом устройстве;
- на обоих открыть Console;
- использовать временную комнату и копию героя.

Обозначения:

- `[ ]` — не проверено;
- `[x]` — работает;
- `[!]` — сломано;
- `[~]` — работает частично.

При критической ошибке, потере данных или дублировании остановить тест и
сохранить скриншот, Console и код комнаты.

- [ ] Автоматического броска нет.
- [ ] Пока кубик не нажат, ход не продолжается.
- [ ] Результат 1–9 даёт одну неудачу.
- [ ] Результат 10–20 даёт один успех.
- [ ] Натуральная 1 даёт две неудачи.
- [ ] Натуральная 20 даёт два успеха.
- [ ] За один раунд нельзя бросить дважды.
- [ ] Прогресс видят ГМ и игрок.
- [ ] Четыре успеха стабилизируют героя.
- [ ] Четыре неудачи переводят героя в состояние смерти.
- [ ] Мёртвый герой не может двигаться, атаковать или кастовать.
- [ ] Жетон мёртвого героя остаётся на сцене с понятной отметкой.
- [ ] Лечение до окончательной смерти возвращает героя по правилу.
- [ ] Возвращение после окончательной смерти требует решения ГМ.
- [ ] Reload сохраняет успехи, неудачи и состояние.

# 15. Каст заклинаний

- [ ] Игрок выбирает освоенное доступное заклинание.
- [ ] Кнопка «Применить» включает выбор цели или точки.
- [ ] Видна дальность и допустимые цели.
- [ ] Круг, линия и конус показывают правильную область.
- [ ] Escape отменяет применение.
- [ ] Отмена не расходует действие или заряд.
- [ ] ГМ получает источник, заклинание, цель и предполагаемый эффект.
- [ ] До подтверждения ГМ ничего не применяется.
- [ ] ГМ может открыть лист цели.
- [ ] ГМ подтверждает урон, лечение, статус и длительность отдельно.
- [ ] Требуемый бросок появляется отдельным окном с кубиком.
- [ ] После подтверждения расходуются правильные действие и заряд.
- [ ] Отмена ГМ ничего не расходует.
- [ ] Результат одинаков в бою, листе и на жетоне.
- [ ] Анимация появляется один раз.
- [ ] Offline-заявка после reconnect не дублируется.
- [ ] Мёртвый или лишённый действия герой не может кастовать.

# 16. Сцена, зоны и визуальные эффекты ГМ

- [ ] ГМ может загрузить фон.
- [ ] Фон виден на карте и в библиотеке.
- [ ] NPC, враг и жетон из картинки создаются один раз.
- [ ] Жетон нормально двигается и изменяет размер.
- [ ] Скрытый объект виден ГМ и не виден игроку.
- [ ] Публикация передаёт игроку правильную сцену.
- [ ] Большое изображение не хранится целиком в Realtime Database.
- [ ] Одинаковое media не создаёт бесконечные дубли.
- [ ] Удаление неиспользуемого media не ломает используемые изображения.
- [ ] Сцена сохраняется как зона.
- [ ] Переход ведёт в выбранную зону.
- [ ] Переходит только выбранный герой.
- [ ] Reconnect возвращает героя в правильную зону.
- [ ] Линейка, круг, линия и конус показывают клетки.
- [ ] Ping виден нужным клиентам.
- [ ] Частицы запускаются на выбранной цели.
- [ ] Анимация жетона не меняет его координаты.
- [ ] Полноэкранные эффекты видны выбранным игрокам.
- [ ] Уровни интенсивности различаются.
- [ ] Одно событие воспроизводится один раз.
- [ ] Старое событие не проигрывается после позднего входа.
- [ ] Эффекты не засоряют чат.

# 17. Offline, несколько вкладок и права

- [ ] Отключить сеть игрока на 10–30 секунд.
- [ ] Разрешённая операция остаётся в очереди.
- [ ] После reconnect она применяется один раз.
- [ ] HP, предмет, статус, журнал, заряд и ход не откатываются.
- [ ] Подтверждённые операции исчезают из очереди.
- [ ] Вторая вкладка показывает предупреждение.
- [ ] Только активная вкладка отправляет операции.
- [ ] Передача управления делает старую вкладку read-only.
- [ ] Две вкладки не создают второго участника.
- [ ] Вторая вкладка ГМ не дублирует выдачу или эффект.
- [ ] Игрок меняет только своего героя.
- [ ] Игрок может лечить своего героя и завершать свой ход.
- [ ] Игрок не меняет чужой лист и время комнаты.
- [ ] Посторонний пользователь не видит скрытые сообщения.
- [ ] Гость не может записывать в комнату.

# 18. Визуальная проверка

Проверить Состояние, Вещи, Магию, Журнал и верхние вкладки отдельно на:

- [ ] 2560×1440;
- [ ] 1920×1080;
- [ ] 1440×900;
- [ ] 1366×768;
- [ ] 1024×768;
- [ ] узком экране 560 px;
- [ ] узком экране 360 px.

На каждом размере:

- [ ] Нет выхода за экран.
- [ ] Нет непредусмотренного общего скролла.
- [ ] Главные кнопки доступны.
- [ ] Текст читается без zoom браузера.
- [ ] Иконки не растянуты.
- [ ] Отступы ровные.
- [ ] Рамки не удвоены.
- [ ] Hover не двигает сетку.
- [ ] Модальные окна помещаются в экран.
- [ ] Нет невидимого слоя, блокирующего карту.

## Как прислать мне визуальную проблему

Скопируй этот короткий блок и приложи скриншот:

```text
Где: экран → вкладка → блок
Роль и разрешение:
Что сейчас плохо:
Как должно выглядеть:
Что нельзя двигать или менять:
Что можно менять:
Скролл: запрещён / только внутри блока / допустим
Нужна анимация:
Нужно новое изображение или текстура:
Когда считаем готовым:
```

Пример:

```text
Где: Сумка → Вещи → две руки
Роль и разрешение: игрок, 1920×1080
Что сейчас плохо: подписи ломаются, ячейки не выглядят одной группой.
Как должно выглядеть: две равные симметричные ячейки.
Что нельзя двигать или менять: внешнюю рамку, ширину колонки и верхние вкладки.
Что можно менять: внутреннюю сетку, отступы, текст и пустое состояние.
Скролл: запрещён.
Нужна анимация: мягкий hover без изменения размера.
Нужно новое изображение или текстура: нет.
Когда считаем готовым: текст читается, ячейки равны, соседи не двигаются.
```

Если нужно сгенерировать изображение, допиши:

```text
Что изображено:
Стиль и палитра:
Фон: прозрачный или полный
Формат и пропорции:
Что оставить пустым под интерфейс:
Что строго не добавлять:
Сколько вариантов:
```

Для рамок, свечения, сетки и hover новое изображение обычно не нужно. Генерация
нужна для пергамента, атмосферного фона, арта предмета, заклинания, места, NPC
или прозрачного слоя льда/огня.
