# Портреты в мобильном листе персонажа

Единая точка входа: `character-portrait.js`, API `ZargotaPortrait.attributes(person, context)`.
Применяется в списке героев, миниатюрах, характеристиках, «Обо мне», карточках людей и дереве связей.
Это только кадрирование: исходные картинки и данные персонажей не меняются.

## Стандарт исходного изображения

- Вертикальный портрет 2:3, желательно от 768 × 1152 px. Не обрезать макушку.
- Главный герой — в центре, лицо примерно на 35% высоты изображения.
- Держать глаза, нос и подбородок внутри центральных 60% ширины; оставлять воздух над головой.
- Не помещать подписи, рамки или кнопки внутрь картинки. Интерфейс рисует их отдельно.
- Для существующих нестандартных иллюстраций задавать точку лица в `presets` по имени файла.
  У Евана фокус приходится на лицо героя, а не на фигуру за ним.

## Кадрирование

Координаты фокуса — проценты **исходной картинки**, а не значение `object-position`.
Не добавлять отдельные `transform:scale(...)` или исключения по `img[src]` в CSS.
Общий код рассчитывает `cover` для реального размера блока и помещает фокус в верхнюю
центральную часть свободной области. Это оставляет место для имени снизу.
Кадр пересчитывается после загрузки изображения, смены персонажа и изменения размеров,
без замены узла картинки или повторного проигрывания анимаций всего листа.

Вызов при создании картинки:

```js
'<img' + ZargotaPortrait.attributes(person, 'lore') + ' src="..." alt="">'
```

Контексты: `sheet`, `roster`, `lore`, `person`, `detail`, `thumb`.
Неизвестные изображения используют фокус 50% / 35%. Для другого расположения лица
нужна точная точка в реестре; автоматического распознавания лиц здесь нет.
Если модель уже предоставляет числовые `portraitFocusX` / `portraitFocusY`, они
имеют приоритет и ограничиваются диапазоном 0–100. Этот модуль ничего не записывает в модель.

## Проверка

`tests/character-portrait-edge.cjs`: реальные портреты всех пяти героев, список,
миниатюры, лист и лор на 320/390/430 px, изменение HP без перезагрузки портрета,
переключение героя и возврат с большого экрана. Проверять лицо также визуально:
математически верная точка не заменяет художественную оценку кадра.

## Иконки славы

В `images/ui/character-mobile/fame-v3/` находятся 16 прозрачных PNG размером 384 × 384 px:
`fame-world-stage-{1..8}-v3.png` и `fame-zargota-stage-{1..8}-v3.png`.
Каждой ступени соответствует отдельное изображение; значение 0 использует приглушённую
первую ступень. Существующие значения славы 0–8 управляют изображением, размером и
свечением, без изменения игровых правил. При `prefers-reduced-motion` движение отключено.
Источники, полные промпты, SHA-256 и проверка прозрачности: `fame-v3/SOURCES.json`.
Прежние PNG v2 сохранены для совместимости; мобильный лор использует набор v3.
