# Ресурсы эпизодов / Ресурси епізодів

RU: Складывайте фоны в `backgrounds`, портреты в `portraits`, объекты в `objects`, изображения для анимаций в `animations`, звуки в `audio`. Можно создавать вложенные папки эпизодов. После добавления файлов выполните `npm run story:assets`. Затем закоммитьте файлы и `catalog.json` вместе. В редакторе нажмите «Из папки ресурсов» и выберите файл. JSON эпизода содержит пути и настройки, а не медиафайлы. GIF воспроизводится как готовая анимация; PNG — изображение для эффектов, не произвольный программный сценарий.

UK: Складайте тло в `backgrounds`, портрети в `portraits`, об’єкти в `objects`, зображення для анімацій в `animations`, звуки в `audio`. Можна створювати вкладені папки епізодів. Після додавання файлів виконайте `npm run story:assets`. Потім закомітьте файли й `catalog.json` разом. У редакторі натисніть «З папки ресурсів» та оберіть файл. JSON епізоду містить шляхи й налаштування, а не медіафайли. GIF відтворюється як готова анімація; PNG — зображення для ефектів, не довільний програмний сценарій.
